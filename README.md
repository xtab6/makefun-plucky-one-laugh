One funny line of at most 200 characters, compared two at a time by a judge model. This entry writes `My therapist fired me for making too much progress in the waiting room.` — 71 characters, one line: the patient gets fired, and the firing is for getting better too fast, in the waiting room, before the session even starts.

## Run it

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there: exactly the 71 characters above, no trailing newline, verified by read-back before it exits.
